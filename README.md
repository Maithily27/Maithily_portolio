# Maithily Gondode — Portfolio v3.0

A completely redesigned portfolio built with React.

## Design Theme
**Deep Ocean / Bioluminescent** — Dark navy background with teal (#00d4c8) and gold (#f0c060) accents.

### Features
- ✅ Animated particle canvas background with connecting lines and grid
- ✅ Loader screen with spinning ring animation
- ✅ Sticky header that becomes frosted glass on scroll
- ✅ Hero section with typewriter effect for roles
- ✅ Education with score display and animated hover cards
- ✅ Skills with animated progress bars + bubble visualization
- ✅ Projects with visual header cards, tech tags, and live/github links
- ✅ Experience with tab-switcher layout showing achievements & tech
- ✅ Certifications in color-coded grid cards
- ✅ Contact form with success state
- ✅ Footer with quick nav links
- ✅ Scroll progress bar
- ✅ Back-to-top button
- ✅ Fully responsive on mobile

## Setup

```bash
npm install
npm start
```

The new rebuild uses only vanilla React — no framer-motion dependency needed (but kept in package.json for optional use). All animations are done with CSS keyframes and JS intersection observer.
